# Mistral EGE Solver

Экспериментальный прототип пайплайна для автоматической обработки вариантов ЕГЭ по математике с помощью Mistral OCR и LLM.

> Проект использовался как ранний прототип. Дальнейшая разработка и более устойчивый пайплайн продолжаются в [exam-parser](https://github.com/MaksimChislavskiy/exam-parser).

## Что делает

```text
PDF по URL
   ↓
Mistral OCR + structured output
   ↓
извлечение условий задач и изображений
   ↓
сопоставление изображений с задачами
   ↓
Mistral Large → решение + короткий ответ
   ↓
tasks.xlsx + images/*.png
```

В коде предусмотрены повторные запросы с exponential backoff при временных ошибках API.

## Настройка

Создайте `.env` в корне проекта:

```env
MISTRAL_API_KEY=your_api_key
```

## Запуск

```bash
python main.py
```

Тестовый PDF задаётся в `PDF_URL` внутри `main.py`.

## Результат

После обработки создаются:

```text
tasks.xlsx
images/
```

Excel содержит поля:

```text
task_num | condition | image_name | solution | answer
```

## Статус

Это исследовательский прототип, сохранённый как часть истории развития решения. В `exam-parser` архитектура была переработана: добавлены более надёжное разделение задач, повторное использование OCR, разные LLM-провайдеры, восстановление после частичных ошибок и дополнительные проверки результата.
